# python-learning

我的 Python 自学仓库。费曼学习法：每天写代码 + 写一篇用自己的话讲懂概念的笔记。

## 项目亮点

**d4_contacts.py —— 菜单式通讯录（第一个完整小产品）**

- 增 / 查 / 删 + while 菜单循环
- json 持久化：启动自动读取存档，退出时询问是否保存，关机不丢数据
- 防呆处理：无效指令提示、删除前探路人名、同名联系人覆盖确认（y/n，大小写兼容）、空通讯录提示

## 费曼笔记

- **d2-notes**：字典在内存，JSON 在磁盘（数据存放的两个世界）
- **d3-notes**：函数与 return（交作业与交白卷的区别）
- **d4-notes**：函数没写 return，交的是白卷
  - 主案：load_contacts 忘写 return → 交回 None 白卷 → 查看时静默放行、删人时才炸
  - 核心结论：**静默失败比崩溃更危险**——崩溃即时暴露，静默失败留到代码变多后爆发，更难排查
  - 额外教训：调用含参函数别漏传参；字典的键不能写死
- **d5-notes**：理解越深，代码越短
  - 主案：d5contacts.json 事故（路径拼接）第一次将json生成地址写死，第二次根目录冒出个没见过的文件
  - 核心结论：拆出文件夹用os.path.dirname路径拼接用os.path.join，两者配合使用
  - 设计判断：添加时候，如果将空名加入字典，会导致后续涉及到搜索名字的功能全部出问题
            而修改和删除的空名不会影响字典成员

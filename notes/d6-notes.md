# d6-notes：不同操作归于各自区域

## 今天的事件
将d5中的项目单文件分成了多文件
## 主案：import * 的静默覆盖
- **现象**：主程序写了 `from d6.contacts_ops import *`，六个函数一股脑涌进来，看不出每个名字是谁家的——假如 ops 里恰好有个 `confirm`，主程序里自己写的 `confirm` 会被它**静默覆盖**，报错都不报
- **原因**：`*` 是"全要"，import 进来的名字和你自己定义的名字处在同一个命名空间，后到的干掉先到的
- **对策**：点名 import，一行看清谁是谁；import 进来的名字撞了，Python 当场报错（大声失败）

## 核心结论：（一句话）
-  不是任何地方都可以简略，要考虑会不会产生bug或者静默失败
